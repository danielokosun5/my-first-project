# Lagos Power Planning Assistant ⚡

This is an AI-powered assistant built using AWS PartyRock.

## 🔗 Live App
[Click here to use the app](https://partyrock.aws/u/Dannyblag5/Zc6ujBY_e/Lagos-Power-Planning-Assistant)

## 💡 What it does
- Helps users plan electricity usage in Lagos
- Suggests power schedules
- Provides smart recommendations based on availability

## 🛠 Built With
- AWS PartyRock
- Amazon Bedrock (Claude)
- Generative AI

## 🚀 How to Use
1. Visit the live app link
2. Enter your location in Lagos
3. Get power schedule recommendations
